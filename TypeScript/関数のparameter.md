# 関数のパラメータについて

## 可変長引数

- 関数呼び出しの際に引数をいくつ渡しても OK
- 全く方安全でない

## レストパラメータ

- パラメータに `...` を用いることで定義できる
- パラメータの最後に一つだけ指定できる

```ts
const sumPrice = (...price: number[]): number => {};
```

## 呼び出しシグネチャ

- シグネチャ

  - 関数名
  - 引数の数
  - 引数の型
  - 戻り値の型

    などの関数を識別する情報のこと

- 呼び出しシグネチャ
  - どのような関数なのかを表現する型定義
  - 省略記法はアロー関数と似た形
  - 完全な記法はオブジェクトと似た形
