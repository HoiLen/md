# 型エイリアス(type)でオブジェクトの型定義

## object 型に意味はない

object 型は object であることを伝えるだけ

TypeScript では object の構造を定義する必要がある

```ts
const a: object = {
  name: 'Nanaha',
  age: 28,
};
a.name; // a というオブジェクトには name というプロパティがないとエラーが出る
```

ではどうするか

## オブジェクトリテラル記法を使う

- 構造を定義する
- 各プロパティに型を宣言

```ts
let country: {
  language: string
  name: string
} = {
  language: 'japanese',
  name: 'Japan',
}
```

## 特別なプロパティを扱う
- オプショナル `?` のついたプロパティはあってもなくてもOK
- `readonly` のついたプロパティは上書きできない

```ts
let nanaha: {
  age: number
  lastName: string
  readonly firstName: string
  gender?: string
} = {
  age:28,
  lastName: 'Yamada',
  firstName: 'Tarou' // 上書きできない
}

nanaha.gender = 'male' // あとから追加できる
nanaha.lastName = 'Kamado' // 上書きできる
```

## オブジェクトの柔軟な型定義
### インデックスシグネチャ
- 指定したパターンのプロパティを複数持つ可能性を示す
- `[key: T]: U` のようにパターンを定義する
- `key` は `string` か `number` のみ

```ts
const capitals: {
  [countryName: string]: string // インデックスシグネチャ
} = {
  Japan: 'Tokyo',
  Korea: 'Seoul'
}

capitals.China = 'Beijing'
capitals.Canada = 'Ottawa'
```

- インデックスシグネチャを使用したオブジェクトは、ほかの型宣言ができない
  ```ts
  const capitals: {
    [countryName: string]: string
    age: number // エラーが出る
  } = {
    Japan: 'Tokyo',
    Korea: 'Seoul',
    age: 23
  }
  ```
  上のように記述すると、
  ```error
  Property 'age' is incompatible with index signature.
  ```
  "`age` はインデックスシグネチャと互換性がない"

  と言われる

## 型エイリアスで型定義を再利用
### 型エイリアス
- `type` で型に名前をつけて宣言できる
- 同じ型のオブジェクトが複数ある場合に有効
- 型に名前をつけることで変数の役割を明確にできる

```ts
type Country = {
  capital: string
  language: string
  name: string
}

const japan: Country = {
  capital: 'Tokyo',
  language: 'Japanese',
  name: 'Japan',
}

const america: Country = {
  capital: 'Washington, D.C.',
  language: 'English',
  name: 'United States of America',
}
```

## Union と Intersection
TypeScriptは型を組み合わせることができる
### Union Types (合併型)
- 少なくとも、型 `A` と型 `b` のどちらかの型を持つ
- 例として、型 `A` のすべてのプロパティと型 `B` の一部のプロパティを持つことができる
  ```ts
  type Knight = {
    hp: number
    sp: number
    swordSKill: string
  }
  type Wizard = {
    hp: number
    mp: number
    magicSKill: string
  }
  type Adventurer = Knight | Wizard // Union
  const adventurer: Adventurer = {
    hp: 100, // 共通
    sp: 30, // Knight 専用パラメータ
    mp: 20, // Wizard 専用パラメータ
    swordSkill: '2連切り', // Knight 専用パラメータ
  }
  ```
### Intersection Types (交差型)
- 型 `A` と型 `b` の両方の型を持つ
- 両方の型すべてを持つ必要がある
  ```ts
  type Knight = {
    hp: number
    sp: number
    swordSKill: string
  }
  type Wizard = {
    hp: number
    mp: number
    magicSKill: string
  }
  type Paladin = Knight & Wizard // Intersection
  const paladin: Paladin = {
    hp: 100, // 共通
    sp: 30, // Knight 専用パラメータ
    mp: 20, // Wizard 専用パラメータ
    swordSkill: '2連切り', // Knight 専用パラメータ
    magicSkill: 'ファイア' // Wizard 専用パラメータ
  }
  ```
