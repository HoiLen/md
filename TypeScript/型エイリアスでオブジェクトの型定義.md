# 型エイリアス(type)でオブジェクトの型定義

## object 型に意味はない

object 型は object であることを伝えるだけ

TypeScript では object の構造を定義する必要がある

```ts
const a: object = {
  name: 'Nanaha',
  age: 28,
};
a.name; // a というオブジェクトには name というプロパティがないとエラーが出る
```

ではどうするか

## オブジェクトリテラル記法を使う

- 構造を定義する
- 各プロパティに型を宣言

```ts
let country: {
  language: string
  name: string
} = {
  language: 'japanese',
  name: 'Japan',
}
```

## 特別なプロパティを扱う
- オプショナル `?` のついたプロパティはあってもなくてもOK
- `readonly` のついたプロパティは上書きできない

```ts
let nanaha: {
  age: number
  lastName: string
  readonly firstName: string
  gender?: string
} = {
  age:28,
  lastName: 'Yamada',
  firstName: 'Tarou' // 上書きできない
}

nanaha.gender = 'male' // あとから追加できる
nanaha.lastName = 'Kamado' // 上書きできる
```
