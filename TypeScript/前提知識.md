# TypeScriptの前提知識
## まずはこの用語
### webpack
モジュールバンドラ(複数のファイルを一つにまとめるもの)であり、この `webpack` はファイルの依存関係を考慮したうえで `JavaScript` を一つのファイルにまとめる

### TypeScript
`JavaScript` に型システムを取り入れた言語

型システムを導入したことによって、エラーを起こしにくいコードの記述ができる

コンパイラを通して `JavaScript` に変換して実行する

## ビルドのしくみ
```mermaid
flowchart LR
.ts -.->|コンパイラ| .js
.js -.->|webpack| bundle.js
bundle.js --> 実行
```
複数の `TypeScript` ファイル（`.ts`）を、コンパイラを通して `JavaScript` ファイル（`.js`）にコンパイルする

コンパイルされた複数の `JavaScript` ファイルを、 `webpack` を使って一つの `JavaScript` ファイル（図では `bundle.js`）にまとめる

一つにまとまった `JavaScript` ファイルを WEB ブラウザで実行
