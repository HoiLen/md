# オブジェクトの代入

配列を新しい変数に代入することを考える

## 配列を直接変数に代入する

```ts
// 配列: any[] を定義
const arrAny: any[] = [] // ---1.
arrAny.push(123) // number[] ---2.
arrAny.push('ABC') // (string | number)[] ---2.

// arr 
const arr = arrAny // ---3.
arr.push(true) // ---4.
console.log('arrAny:', arrAny) // ---5.
```

出力はこうなる

```console
arrAny:[123, 'ABC', true]
```

上から順番に見ていく

1. `arrAny` を `any[]` 型で宣言

2. `arrAny.push` で値の追加（型は `(string | number)[]` ）

3. `arr` に配列 `arrAny` を代入
    ここで、配列はオブジェクト型であるため、値の渡し方は **参照渡し** となる
    そのため、`arr` と `arrAny` は同じオブジェクトを指しており、値は `arr` と `arrAny` で共有されている状態にある

4. `arr.push(true)` で `arr` が指しているオブジェクトに `true` を追加（型は `(boolean | string | number)[]`）

5. `arrAny` が指しているオブジェクトの情報を出力する


## 関数の返り値として配列を受け取る

```ts
const generateSomeArray = () => {
    const _someArray = [] // any[]
    _someArray.push(123) // number[]
    _someArray.push('ABC') // (string|number)[]

    return _someArray
}
const someArray = generateSomeArray()
someArray.push(456)
// someArray.push(true) // NG
console.log('someArray:', someArray)
```

出力はこうなる

```console
someArray:[123, 'ABC', 456]
```

新しく宣言した `someArray` の部分に着目する

```ts
const someArray = generateSomeArray() // return _someArray
```

変数 `someArray` は関数 `generateSomeArray()` の返り値である `_someArray` を受け取っているが、これは **参照渡しではなく、新しく配列を生成する** という挙動になる

そのため、`_someArray` と `someArray` はそれぞれ異なるオブジェクトを指している

`_someArray` は `any[]` 型であるため `push` により型を拡張できるが、 `someArray` は `generateSomeArray()` で受け取った時点で `(string | number)[]` 型であるため、ここから `push` で `boolean` 型を追加しようとするとエラーになる
