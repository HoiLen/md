# ジェネリック型

型の種類は異なるが同じデータの構造をしており、共通化できそう
```ts
const stringReduce = (array: string[], initialValue: string): string => {}
const numberReduce = (array: number[], initialValue: number): number => {}
```

## ジェネリック型パラメータ
- 型をパラメータ化する
- `T, U, V, W` などがよく使われる

```ts
// 型エイリアス(type)で宣言
type GenericReduce<T> = {
    (array: T[], initialValue: T): T
}

// 関数宣言時に具体的な型をバインド（ここでは string 型）
const reduce: GenericReduce<string> = (array, initialValue) => {}
```
