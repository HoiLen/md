# 型について
## 型推論と明示的な型定義
* TypeScript は型を自動で推論する
  ```ts
  // string 型と推論される
  const name = 'chappy'
  ```
* 型アノテーションを使うことで明示的な型宣言が可能
  ```ts
  // 明示的に string と宣言
  const name: string = 'chappy'
  ```

## 型の種類
### プリミティブ型
* `string` 型 :
    すべての文字列を扱う型
* `number` 型 :
    整数、浮動小数点数、正数、負数、Infinity、NaN（非数）などすべての数値を扱う型
* `boolean` 型 :
    `true` `false` の２つの値を扱う型

### 存在しないことを表現する型
* `null` :
    値が欠如していることを表す
* `undefined` :
    初期化されておらず値が割り当てられていないことを表す
    できるだけ `undefined` を使う

### `null` `undefined` の型判定
どちらも `if( !(変数名) ){}` で型判定ができる
```ts
let name = null
console.log('notExist Sample 1:', typeof name, name) // object 型と出る

if (!name) {
    // null だったらこちらが実行される
    console.log('notExist Sample 2:', '吾輩は猫である。名前はまだ' + name)
} else {
    console.log('notExist Sample 3:', '吾輩は猫である。名前は' + name)
}

let age = undefined
console.log('notExist Sample 4:', typeof age, age) // undefined 型と出る

if (!age) {
    // undefined だったらこちらが実行される
    console.log('notExist Sample 5:', '年齢は秘密です')
} else {
    console.log('notExist Sample 6:', '年齢は' + age + '才です')
}
```

## `any` と `unknown`
* `any` :
  どんな型でも許容する
  安全でないので基本ダメ
* `unknown` :
  どんな型になるか不明
  代入した値によって型が変化

どんな型を宣言すればよいか分からないときは、`unknown` で宣言して処理するときに if 文で型を判定する
