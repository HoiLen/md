# 配列の型定義

## 配列

`T[]` の形で宣言できる

```ts
const colors: string[] = ['red', 'blue']
colors.push('green') // OK
colors.push(123) // NG
```

`Array<T>` の形でも宣言できる

```ts
const even: Array<number> = [2, 4, 6]
```

合併型 `Union` も使える

```ts
const ids: (string | number)[] = ['ABC', 123]
ids.push('DEF', 456) // OK
```

アノテーションしなくても、型推論される

配列の受け渡しについては以下を参照
[オブジェクトの代入.md](./オブジェクトの代入.md)

```ts
const generateSomeArray = () => {
    const _someArray = [] // any[]
    _someArray.push(123) // number[]
    _someArray.push('ABC') // (string | number)[]
    return _someArray
}

const someArray = generateSomeArray()
someArray.push(true) // NG
```

## タプル

### タプルとは
一言でいうと、**厳格な配列**

タプルは配列の各要素に型と数を定義できる

```ts
// 一般的なタプルの型定義
let response: [number, string] = [200, 'OK']
response = [400, 'Good Request'] // OK
response = [400, 'Bad Request', 'Email parameter is missing'] // NG
response = ['400', 'Bad Request'] // NG


// 可変長引数を用いたタプル
const friends: [string, ...string[]] = ['Kana']
friends.push('Takumi')
friends.push('Kenji')
```

## イミュータブルな配列

プリミティブ型 `number` `string` `boolean` は `const` で宣言するとイミュータブル（書き換え不可）となる

配列は `const` で宣言してもミュータブル（書き換え可能）

```ts
const mutableNumbers: number[] = [1, 2, 3]
mutableNumbers[2] = 4 // OK
```

`readonly` を使えばイミュータブルな配列 / タプルを作れる

```ts
const commands: readonly string[] = ['git add', 'git commit', 'git push']
commands.push('git fetch') // NG
commands[2] = 'git pull' // NG

const numbers: ReadonlyArray<number> = [1, 2, 3]
const names: Readonly<string[]> = ['Shinya', 'Makishima']
```
