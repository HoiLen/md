# 配列の型定義

`T[]` の形で宣言できる

```ts
const colors: string[] = ['red', 'blue']
colors.push('green') // OK
colors.push(123) // NG
```

`Array<T>` の形でも宣言できる

```ts
const even: Array<number> = [2, 4, 6]
```

合併型 `Union` も使える

```ts
const ids: (string | number)[] = ['ABC', 123]
ids.push('DEF', 456) // OK
```
