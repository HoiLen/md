# 設計クラスの使用方法
実行クラス
```java
class Jikkou {
	public static void main(String[] args){
		Sekkei calc = new Sekkei();
		int z = calc.calculate(5,6);
		calc.output((String)z);
	}
}
```
設計クラス
```java:Sekkei.java
class Sekkei {
	//結果を出力するメソッド
	void output(String msg){
		System.out.println("計算結果:" + msg);
	}
	//計算するメソッド
	int calculate(int x, int y){
		return x + y;
	}
}
```
実行結果
```bash
計算結果:11
```

## 手順
1. 実行クラス側で、使いたい設計クラス`Sekkei`のオブジェクト`calc`を生成
	```java
	//オブジェクト宣言
	Sekkei calc = new Sekkei();
	```
2. 実行クラス側で、`calc.`の後に使いたいメソッド名を入力する
	```java
	int z = calc.calculate(5,6);
	calc.output((String)z);
	```
