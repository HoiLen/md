# ソートについて
## バブルソート

昇順
```java
int[] arr = {5,7,2,8,1,3,4,6};

for(int i=0; i<arr.length;i++){
    for(int j=0; j<arr.length-i-1;j++){
        if(arr[j] > arr[j+1]){
            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;
        }
    }
}
```
`j` のループの１週で必ず一番大きい数が配列の一番最後に来る。

降順にするには `if` の比較演算子を逆 `<` にする
