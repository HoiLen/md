# アノテーションやform:actionの変更したときに必要なこと OR 404 not found と出た時に確認すること
サーブレットのアノテーション`@WebServlet("/~~~~~~")`やHTMLの`<form action="/project/~~~~~~"></form>`を変更したとき、サーバーを立ち上げてリクエストを送るときに404 not foundというエラーが出る時がある。

## 確認すること
1. まずはアノテーションとHTMLの`action`が一致しているかを確認する
   
2. 一致しているなら、Eclipseのメニューバーからプロジェクト -> クリーンを選択する
   こうすることで、プロジェクトをbuildしなおすことができ、設定が正しく反映されることが多い
