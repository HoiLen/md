# キャスト

`double`型から`int`型に代入することを考える。
`double`は64bitで`int`は32bit
大きいサイズの型から小さいサイズの型には代入できないので、
```java
double a = 3.14159;
int b = a;
```
とすると、型の不一致としてエラーとなる。

そういう時は **キャスト** を使う
```java
double a = 3.14159;
int b = (int)a;//出力:3
```
上記の場合は、小数点以下がすべて切り捨てられる。

## キャストの応用（あんまり使わん）
`pi`を少数第3位以降を切り捨て
```java
double pi = 3.141592;

pi = (int)(pi * 100);// 左辺のpi = 314 <=この時点で切り捨てられている
pi = pi / 100;// 314を100で割って3.14

System.out.println(pi);// 出力:3.14
```
