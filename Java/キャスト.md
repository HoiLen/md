# キャスト

`double`型から`int`型に代入することを考える。
`double`は64bitで`int`は32bit
大きいサイズの型から小さいサイズの型には代入できないので、
```java
double a = 3.14159;
int b = a;
```
とすると、型の不一致としてエラーとなる。

そういう時は **キャスト** を使う
```java
double a = 3.14159;
int b = (int)a;//出力:3
```
上記の場合は、小数点以下がすべて切り捨てられる。

## キャストの応用
### 少数2位だけを取り出す
1. 少数を持つ変数に`100`をかけて`int`型にキャストすると、小数2位が1の位に移動し、小数3位以下が切り捨てられる。
2. `10`の剰余を計算すると取り出せる。
```java
double rand = Math.random(); // 0.1688887236
int num = (int)(rand*100) % 10; // 16 % 10
System.out.println(num); // 6
```

つまり、小数`n`位の値だけを取り出すには、
```java
(int)(rand * 10 ^ n) % 10
```
上記のような式を書けばよい。
### `pi`を少数第3位以降を切り捨て
```java
double pi = 3.141592;

pi = (int)(pi * 100);// 左辺のpi = 314 <=この時点で切り捨てられている
pi = pi / 100;// 314を100で割って3.14

System.out.println(pi);// 出力:3.14
```
