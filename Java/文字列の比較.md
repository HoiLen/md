# 文字列の比較
`String`型の比較をするときは少し注意が必要

* 2つの`String`型の変数が等しいか判定をする関数
	```java
	str1.equals(str2)
	```

* 2つの変数が同じインスタンスかを比較
	```java
	str1 == str2
	```
	`==`で比較しても変数内の文字列で比較してくれないので注意

ex)
```java
public static void main(String[] args) {
	System.out.println("入力した文字列を比較します");
	
	if(args[0].equals(args[1])) {
		System.out.println("入力した文字列は等しいです");
	}else {
		System.out.println("入力した文字列は異なります");
	}
	
	if(args[0] == args[1]) {
		System.out.println("インスタンスが等しいです");
	}else {
		System.out.println("インスタンスが異なります");
	}
}
```
