# 配列

- 配列は参照型であるため、
    
    ```java
    int[] arr = {1,2,3};
    System.out.println(arr);
    ```
    
    とすると出力されるのは配列`arr`の値が格納されているアドレスとなる。  
    そのため、値を取り出すなら、
    
    ```java
    System.out.println(arr[0])
    ```
    
    上記のように index を指定するか、
    
    ```java
    for(int i=0; i<arr.length; i++){
        System.out.println(arr[i]);
    }
    ```
    
    として全要素を取り出す。  
    indexが必要なく、要素だけをすべて取り出すなら、
    
    ```java
    for(int i : arr){
        System.out.println(i);
    }
    ```
    
    としてもよい。
