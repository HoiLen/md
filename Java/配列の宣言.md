# 配列の宣言
配列の宣言の方法をちょっとまとめる。
1. まとめて宣言
```java
String[] color = {
	"黄色",
	"黄緑",
	"緑",
	"水色",
	"青",
	"紫",
	"ピンク",
	"赤",
	"オレンジ",
	"茶色"
};
```
この方法だと、ぱっと見で要素数がわからない

2. 要素数を指定して命令文で代入
```java
int[] a = new int[3];

a[0] = 0;
a[1] = 1;
a[2] = 2;
```
この方法だと、要素数をあらかじめ宣言するため、わかりやすいが、代入の処理は命令なのでメソッド内にしか書けない。例えば下のようになる。
```java
class Main {

//ここに書くと代入操作が実行されないのでエラーになる
//  int[] a = new int[3];
//  a[0] = 0;
//  a[1] = 1;
//  a[2] = 2;

    public static void main(String[] args){
        int[] a = new int[3];
        a[0] = 0;
        a[1] = 1;
        a[2] = 2;
    }
}
```
3. ブロックを使って要素数と要素の宣言を同時に記述

そこで、変数宣言の後に`{}`を使って下のように書くと
```java
class Main {
    int[] a = new int[3];{
	    a[0] = 0;
	    a[1] = 1;
        a[2] = 2;
    }
    public static void main(String[] args){

    }
}
```
エラーにならず、クラス直下でも宣言できる。
