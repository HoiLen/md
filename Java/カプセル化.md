# カプセル化
`public` `protected` `private` などのアクセス修飾子で、クラス・メンバ変数・メソッドの公開範囲を指定できる。

## private

```java
class Method {
    private int number;
    String name;

    void setNumber(int n){
        number = n;
    }
}
```

```java
class Main {
    public static void main(String[] args) {
        Method m = new Method();
        m.name = "Yamamoto";
        m.number = 20; // <= エラーになる
        m.setNumber(20); // <= private変数に代入できる
    }
}
```
